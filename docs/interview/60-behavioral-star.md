# 60 — Behavioral Interviews (STAR)

## 1. Why it matters

Senior roles weigh ownership, communication, and judgment as much as coding. Strong stories beat vague claims.

## 2. Core concepts

### STAR method

| Letter | Meaning | Tip |
|--------|---------|-----|
| **S** | Situation | Context in 1–2 sentences |
| **T** | Task | Your responsibility / goal |
| **A** | Action | What *you* did (verbs, decisions) |
| **R** | Result | Outcome + metrics + learning |

### Story bank (prepare 6–8)

1. Delivered impact under ambiguity
2. Technical leadership / mentoring
3. Conflict with a peer or stakeholder
4. Failure or incident + recovery
5. Performance / reliability win
6. Cross-team collaboration
7. Saying no / prioritization
8. Learning a new stack quickly (Java/Vue!)

### Quantify

Prefer “reduced p95 latency 40%” over “made it faster.” If no hard metric, use qualitative + scope (“unblocked 3 teams”).

## 3. Code examples

Not code — example outline:

**S:** Payment webhooks duplicated charges in staging.  
**T:** Own root-cause before launch.  
**A:** Added idempotency keys, tests, dashboard alert.  
**R:** Zero duplicate charges in prod first month; pattern reused by 2 services.

## 4. Gotchas / interview traps

- “We” without clarifying your role.
- Skipping the Result.
- Blaming others without accountability.
- Rambling > 3–4 minutes — structure tightly.
- No questions for the interviewer.

## 5. Resources

- Practice aloud; record yourself once.
- Map each story to common prompts (leadership, conflict, failure, impact).

## 6. Self-check

1. **Q:** STAR expands to?  
   **A:** Situation, Task, Action, Result.

2. **Q:** How many prepared stories?  
   **A:** About 6–8 reusable ones.

3. **Q:** Best Result includes?  
   **A:** Measurable impact and/or learning.

4. **Q:** Conflict story must show?  
   **A:** Empathy, clear communication, resolution.

5. **Q:** Failure story must show?  
   **A:** Ownership, remediation, prevention.

6. **Q:** Why quantify?  
   **A:** Makes impact concrete and memorable.

7. **Q:** Avoid what pronoun pitfall?  
   **A:** Unclear “we” that hides your contribution.

8. **Q:** Good closing move?  
   **A:** Thoughtful questions about team, stack, success metrics.

9. **Q:** How reuse stories?  
   **A:** Same story, different emphasis for different prompts.

10. **Q:** Senior signal in behavioral?  
    **A:** Tradeoff thinking, mentorship, system-level ownership.
