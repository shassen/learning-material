# Vue Practice

Vite + Vue 3 + Vue Router + Pinia scratch app for learning Vue from scratch (and mapping from React).

## Setup

```bash
cd practice/vue
npm install
npm run dev
```

## Goals

- Composition API (`ref`, `reactive`, `computed`, `watch`)
- Single-file components
- Vue Router navigation
- Pinia store

See [docs/frontend/42-vue.md](../../docs/frontend/42-vue.md).
