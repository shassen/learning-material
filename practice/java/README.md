# Java Practice

Maven + JUnit 5 drills for learning Java from scratch.

## Prerequisites

Install a JDK 17+ and Maven:

```bash
# macOS (Homebrew)
brew install openjdk@17 maven
```

## Run

```bash
cd practice/java
mvn test
```

## Layout

- `src/main/java/com/learning/` — implementations
- `src/test/java/com/learning/` — JUnit tests

Start with `HelloWorld`, then work through exercise classes added in the Java depth phase.
